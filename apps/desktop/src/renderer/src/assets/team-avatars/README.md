# Team portraits

The twelve defaults were generated as original OpenOrc artwork. Each has a distinct sculptural silhouette, two upright charcoal eyes, and a transparent background. The final files are 256 × 256 RGBA PNGs, included under the project's Apache-2.0 terms.

Keep filenames and zero-based indexes stable: saved member choices refer to them. The first portrait is labelled Hollow while its existing filename remains `avatar-01-facet.png`.

Generated originals were downsampled to 220 × 220 and padded with transparency to 256 × 256 using macOS `sips`. Fold uses 212 × 212 before padding to retain its wider silhouette. Portal's open arch received alpha cleanup. Preserve transparency, antialiased edges, and readable eyes when replacing an asset; check it at the actual UI size.
